# ぐるっと山手線（PWA版）

山手線30駅を歩いて一周する日のための記録アプリです。GitHub Pages に置くと、iPhoneのホーム画面からアプリのように起動でき、電波がない場所でも開けます。

## フォルダの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面での名前・アイコン・全画面起動の設定 |
| `sw.js` | オフラインで起動するための仕組み（service worker） |
| `icons/` | ホーム画面などのアイコン |
| `.nojekyll` | GitHub Pages にファイルをそのまま公開させるための空ファイル |

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`gurutto-yamanote`、Public）。
2. リポジトリの画面で **Add file → Upload files** を開き、このフォルダの中身をすべてドラッグして **Commit changes**。
   - `icons` フォルダはフォルダごとドラッグします。
   - `.nojekyll` は隠しファイルなので、見えない場合はなくても動きます。
3. **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main** と **/(root)** にして **Save**。
4. 1〜2分待つと、`https://（ユーザー名）.github.io/gurutto-yamanote/` で公開されます。

## iPhoneに入れる

1. 公開したURLを **Safari** で開く。
2. 共有ボタン（四角から上向き矢印）→ **ホーム画面に追加** → **追加**。
3. 以後はホーム画面のアイコンから起動します。一度開けば、電波がなくても起動できます。

## 記録の引っ越し

- 公開場所が変わると、記録と写真は自動では引き継がれません。
- 引き継ぐときは、元のアプリの **設定 → 記録を書き出す** でファイルを保存し、新しいアプリの **設定 → 記録を読み込む** でそのファイルを選びます（写真も含まれます）。
- 当日の朝など、念のためのバックアップにも使えます。

## アプリを更新するとき

1. 変更した `index.html` などを、同じリポジトリにアップロードし直す。
2. `sw.js` の1行目近くにある `VERSION = "..."` を新しい値（例：日付）に書き換えてアップロードする。
3. iPhoneでアプリを一度開くと、裏で新しい版が取り込まれます。次に開いたときから新しい版になります。

## 注意

- 記録と写真は、iPhoneのSafari（ホーム画面のアプリ）の中にだけ保存されます。
- ホーム画面に追加したアプリと、Safariのタブで開いたページは、記録が別々になることがあります。当日はホーム画面のアイコンから使ってください。
- 長期間開かないと、iPhoneがデータを消すことがあります。大事な記録は「記録を書き出す」で保存しておくと安心です。
